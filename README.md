# IG-Downloader
Download an entire instagram profile only typing their @
# Instalation

Download the repository
```bash
git clone https://github.com/Jcmora21/IG-Downloader.git
```
Open the folder
```bash
cd IG-Downloader
```
Install the libraries
```bash
pip install instaloader
```
and
```bash
pip install sys
```
Run the python file
```bash
python3 IG-Downloader.py
```
or
```bash
python IG-Downloader.py
```
